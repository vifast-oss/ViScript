| `json.decode("{{\"ten\": \"An\", \"tuoi\": 20}}")` | `Ok(Obj({"ten": Str(An), "tuoi": Num(20)}))` |
| `json.decode("[1,")` + match `Err(e)` | `loi JSON: JSON không hợp lệ ở byte 3: hết chuỗi khi đang chờ giá trị` |
| `let r = json.decode("[1,") else: return -1` | nhánh else lấy → `-1` |
| `json.encode(Ok(1))` / `encode(Err("hỏng"))` | `{"ok":1}` / `{"err":"hỏng"}` |
| `encode(Some(42))` / `encode(None)` | `42` / `null` |
| `encode([1,2,3])` | `[1,2,3]` |
| `encode(map[str,int])` | `{"a":1,"b":2}` |

**Lưu ý các demo vấp** (để A0/nhà trường khỏi mắc):
- `{` trong string bắt nội suy — literal brace phải viết `{{` (chẳng hạn `"{{\"ten\": \"An\"}}"`).
- `fn main` là entry — mã ngoài `fn main`/`let` top-level **không** chạy; gọi từ `main()` để minh hoạ.
- pattern trong `match` dùng ctor **viết hoa** `Some(v)` / `Err(e)`; tên thuần thường bị hiểu là ctor lạ (`VS0203`).
- `(x: int?) => x` **không parse** (VS0201); lambda param annot không tồn tại.
- json heterogeneous `[1, "x"]` bị chặn `VS0412` (typed list).
